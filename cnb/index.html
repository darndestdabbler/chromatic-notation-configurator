Chromatic Notation Configurator

Design a chromatic notation system and export it for the CNB LilyPond engine. The page owns one shared config object (the UI shell owns state; rendering modules stay pure): the editors below write their config slices through change callbacks, and the preview, save/load, and export panels read the same object through accessors. Save/load uses the JSON native format (Module 17); the .ly export (Module 18) is the one-way artifact consumed by LilyPond.
