The UI-shell wiring this page hosts is the session-set 006 integration pattern: one shared config object owned by the page, edited through the Palette Editor (Module 12, set 004), the Staff/Ledger Rule Editor (Module 13) and the Common Properties Editor (Module 15, both set 005), and exported through Module 18. The export button validates first (LY spec §8) — blocking errors are listed with the reason export is blocked, warnings never block — then downloads CNBLilypond.generate(config) verbatim as a .ly file named per meta.fileSuffix/meta.configName.
