Session 18: The preview shows what repeat mode engraves

Why. In repeat mode the engine engraves a minim as two heads, a semibreve and a breve as four, spaced by cnb:multinote-padding. The preview draws one head per note, so the operator cannot see repeat mode or judge the multinote padding setting (architecture §11, open question 3). Separately, the 45deg-369 config had key signatures enabled with no key defined, so no signature could draw, and nothing said why.

  1. Register.
  2. In repeat mode, the card draws each duration's repeated heads as the engine lays them out (counts as the engine engraves them: minim ×2, semibreve ×4, breve ×4), spaced by engine.multinotePadding in staff spaces, with stems and ledgers following. shape mode is unchanged and byte-identical (the preview baseline pins it).
  3. Check the spacing against an engine render of the Kite and 45deg-369 fixtures, as session 11's notehead-size test does.
  4. The key-signature panel and the preview's key selector say when keys are enabled but none is defined or selected, so nothing draws.
  5. README "Preview-only settings": repeat counts are no longer preview-only if the counts now follow the engine; say what remains.
