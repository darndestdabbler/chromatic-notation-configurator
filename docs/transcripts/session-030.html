Session 30: The clef and the key signature reach LilyPond

Why. The engine has taken a clef and key-signature configuration since its sets 005 and 006 (July 2026), and their handoffs list this repository's side as owed (engine docs/planning/configurator-coordination-backlog.md §1–§2): the exporter still writes nothing for either. So the preview and the engraving disagree. Every export, even one with the clef off, engraves the engine's default dozenal clef, which the preview does not draw, and a config that turns its key signature off still engraves one.

  1. Register.
  2. Read the two handoffs first: docs/session-sets/005-clef-configurability/configurator-handoff.md §5 and 006-keysig-configurability/configurator-handoff.md §3 in the engine repo. Their flags set the conversions: the clef anchor's middle-C = 0 origin, the gutter from px to semitones, the clef path's command-list format, the text label's colour and font, the thicknessPct conversion (thicknessPct / (10 × semitones per staff space)), the tonic octave's numbering on a linear staff (the handoff's −1, which the session-3 round trip found does not apply under a pitch axis), and a separator that is off with no engine switch for it.
  3. Export, emit-if-changed like the other engine settings:
  • Clef: cnb:clef-style ('none when the clef is off, 'custom with the glyph registered by cnb:register-clef! and named by cnb:clef-name, 'text with cnb:clef-text), and the size and gutter settings.
  • Key signature: cnb:keysig-style ('none when it is off), the bar's colour, thickness and extent, and cnb:keysig-tonic-octave on linear staves too. Decide, and record in the spec, whether the default config, whose clef is off, exports 'none (the preview's answer) or leaves the engine's dozenal clef; either way the default export baseline changes only on purpose, and the change is named in CHANGELOG.md.
  1. Lift the tests that pin "no clef token" and "no keysig token", add the addendum to docs/CNB-LY-EXPORT-SPEC-v1_3.md (1.3.5), and update the architecture plan §4.9 and §4.12, which say nothing is emitted.
