Work Plan

Build the key-signature editor of design docs/planning/key-signature-designer-design.md section 13.8 in the Key signature panel (cnb/ui/key-signature-editor.js, Module 23), as the mock-ups in docs/planning/key-signature-editor-mockups/ show it. The panel heads with Show the key signature and Start from (The noteheads, Traditional sharps and flats), which replaces the signature's settings after asking to confirm, keeping Show and the picked key. Beneath it the key picker (the staff's own tonic and mode, which it changes too), the Edit layer chips (all marks, naturals, flats, sharps, on a line or ledger, in a space, every second stack) and the magnified canvas: the picked key's signature drawn through CNBKeySignature.render on a grid context at 24 px a semitone, with the staff's lines near the marks and the marks' ledgers, its height capped at 360 px and scrolling inside. A click on a mark selects its spelling's layer, or the layer picked in Edit, and the base or the added symbol clicked; the selection shows its reference point, its box and a corner handle. Dragging a symbol sets the layer's offset, or an added symbol's own offset; the handle sets the symbol's size, or signs.heightSemis for a sign; values snap to tenths of a semitone and show beside the handle while dragging, and one drag is one change, so one step of undo. Beside the canvas the look card: the notehead panel's thumbnails with Emmentaler's sharp and flat as two more, Import from SVG with the imported symbol shown enlarged, its reference point set by a click, and Takes ledger lines (on for naturals and all marks, off for flats and sharps), fill, colour, size (Automatic for the signs, kept), offset fields, and up to two added symbols, the selection named Base, Added 1 or Added 2, each removable, each field's as-beneath clearing it, and a line saying the edit applies to the category in every key. Beneath the canvas the picked mode's 15 keys as small signatures at the staff's scale, a click picking one, a key whose marks touch outlined with the number of places, and a line saying how many of the 105 keys have touching marks, opening a list whose keys pick their tonic and mode. The touch check of design section 13.7 runs over the 105 keys (every line set's copy and the seams included), comparing whole marks in the same and neighbouring stacks by their boxes and then by their ink rasterised into a small mask, a hollow mark's cut-out excluded, after a change and not while a drag moves; it is a warning in the checks list, never blocking the export. Notes gains The sharps or flats only and Stacks the cycle of fifths with its heights and window; Place stays. The rows the editor replaces are removed: Draw, Looks, Size and the overlap note (with marks().overlaps, which only the note read). A UAT driver covers each drag and choice, with screenshots at 1440 and 1280 px judged against the mock-ups; the architecture plan, the README and docs/uat-status.md follow.

Editor canvas

Add the magnified canvas to the Key signature panel (cnb/ui/key-signature-editor.js): the picked key's signature drawn through CNBKeySignature.render on a grid context at 24 px a semitone, with the staff's lines near the marks and the marks' ledgers, in a box whose height is capped at 360 px and scrolls inside. CNBKeySignature.render marks each drawn symbol with its mark and symbol index (data attributes) so a click can tell which was hit; nothing else in the drawing changes. A click on a mark selects its spelling's layer (naturals, flats or sharps) unless another layer is picked in Edit, which then stays picked, and the base or the added symbol clicked; the selection shows the reference point, the symbol's box with its other instances in the key outlined, and a corner handle. Dragging the symbol sets the layer's offset (an added symbol's own offset); dragging the handle sets the symbol's heightSemis and widthSemis (kept in proportion), or signs.heightSemis for a sign; values snap to tenths of a semitone (a loaded value is never snapped), show beside the handle while dragging, and the panel redraws locally while the pointer moves and emits one onChange when it is released, so one drag is one step of undo. Pointer events are wired as element properties, so the tests drive them in Node. Pure helpers with tests in cnb/tests/cnb-key-signature-editor-tests.js: snap, the layer a click selects, and the offset and size a drag of a given distance writes; plus tests that a click selects, a drag emits once with the snapped offset, a handle drag sets the size and a sign's handle sets signs.heightSemis. Test in cnb/tests/cnb-key-signature-tests.js for the symbol markers. Styles in cnb/ui/app.css.
