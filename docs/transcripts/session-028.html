Pitch panel

Create cnb/ui/pitch-panel.js (CNBPitchPanel), with the editor contract of the other cnb/ui modules (plain DOM, property-wired events, Node-testable). render(container, { getConfig, onChange, onOpenAdvanced }) draws the Pitch section (design §3, mock-up 3). Middle of the staff is a select of the twelve pitch classes, and changing it applies CNBPitchModel.shiftPitch by renameDelta from the current middle. It says this is the same as dragging the labels. Staff spacing is a decimal field in semitones per staff space, and a valid change writes writeNudges with the current nudges. Nudges are one control per pitch class, a slider and number field from −1 to +1. Each shows its value and is limited by nudgeLimits, and the bar is shaded to show how far the note can go. A note at a neighbour's spot is marked "shares". C's control is fixed at 0 as the reference. A change writes writeNudges. When readNudges gives null, the section says "This file uses a custom pitch axis that nudges can't show", the nudge controls and spacing field are disabled, and a button calls onOpenAdvanced. The module also exports nudgeControl(host, { config, pc, onChange }), the one-pitch-class control the notehead panel reuses. Tests in a new cnb/tests/cnb-pitch-panel-tests.js, added to cnb/tests/run-tests.js: the controls on the default config and on Twinline (the §3.3 values and the shared marks), a middle-of-staff change, a spacing change (decimal accepted, non-positive refused), a nudge change and its limits, C fixed, every nudge back at 0 removing pitchAxis, the custom-map fallback, and a stride-7 map kept unchanged until a control changes.
