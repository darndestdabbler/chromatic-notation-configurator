Session 72: A repeated minim's stem on its notehead

Why. The engine places the stem the same way (cnb:stem-attachment in its cnb/stems.ly), so it changes too, in engine session 43 (released as engine 1.9.0, engine session 44), after this session decides the rule; session 73 runs the engine round trip once that release is out, as sessions 58 and 59 did.

  2.
